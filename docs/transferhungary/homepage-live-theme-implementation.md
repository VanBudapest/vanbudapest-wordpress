# TransferHungary Homepage – Live Theme Implementation Package

## Working Rule

Keep the existing live homepage theme and section order.

Do **not** rebuild the visual system before the content, SEO and CTA layers are corrected.

This package is built for the current live homepage structure and is meant to be implemented inside the existing theme blocks.

## Positioning

TransferHungary should be positioned as a **private group transportation specialist** for Budapest and Hungary, focused on groups of **6–69 passengers**.

Core message:

– private service only
– vans, minibuses and coaches
– Budapest-first, Hungary-wide
– airport transfers, event transport, day trips and long-distance routes
– English-speaking drivers
– quote-first conversion model
